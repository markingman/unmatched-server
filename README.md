# Generic Unmatched Server

This container is designed to work with a load balancer as a lightweight response server. It can:
- return a generic HTTP 400 response for any unknown host requests
- return an HTTP 503 response for a specific host (useful during short maintenance periods when the actual server is offline)
- return an HTTP 200 response for any request to `/hc` (for health checks)

## Usage

Run `make --help` to see available commands.

### Basic setup
1. Run `make cert` to create a self-signed certificate with a long expiry date.
2. Run `make conf` to build the Nginx configuration file (`nginx.conf`), which is copied by the `Dockerfile`.

Next, use the `README.env` template to create a corresponding `.env` file.

### Local testing
Run `make run` to test the container locally.

### Deployment
To deploy to Google Artifact Registry, run `./deploy.sh --deploy` (other commands are shown from `--help`).

## Notes

- The Nginx config is generated by `make_config.sh`.
- The HTML error message for HTTP 400 responses is defined in `error400.html`.
- The HTML maintenance message for HTTP 503 responses is defined in `error503.html`.
